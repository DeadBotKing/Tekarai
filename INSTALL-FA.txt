مرتب‌سازی منوی سمت راست تکرای — نسخه نصب‌شده روی IIS

ترتیب اصلی: خانه؛ نگهداری و تعمیرات؛ اسناد؛ گفتگو؛ مدیریت؛ هوشمندی؛ پروژه‌ها و وظایف در آخر.
داخل نگهداری و تعمیرات: عملیات (دستورکارها اول)؛ داشبوردها؛ تجهیزات؛ مجوزهای کار؛ انبار؛ تدارکات؛ گزارش‌ها.
این ترتیب ثابت و مبتنی بر کاربرد روزمره است، نه رتبه‌بندی خودکار بر اساس آمار کلیک.

نصب روی سرور فعلی:
۱. بسته را در C:\TkMenu استخراج کنید؛ همه فایل‌ها کنار هم باشند.
۲. سایت و اجرای خودکار فعلی روشن بمانند؛ نیازی به توقف بک‌اند، SQL یا WSL نیست.
۳. در PowerShell ادمین اجرا کنید:
powershell.exe -ExecutionPolicy Bypass -File "C:\TkMenu\Install-Menu-Update.ps1"
۴. موفقیت با MENU_UPDATE_COMPLETED مشخص می‌شود. سپس https://tekarai را با Ctrl+Shift+R تازه‌سازی کنید.
۵. در صورت خطا دوباره اجرا نکنید؛ متن خطا را برای بررسی بفرستید.

ابزار از navigation.ts قبلی پشتیبان می‌گیرد، فقط همان فایل منو را در پروژه جایگزین می‌کند، npm run build را اجرا می‌کند، از IIS پشتیبان می‌گیرد و یک release تازه فرانت‌اند می‌سازد و به سایت Tekarai وصل می‌کند. سایر سایت‌های IIS، اتصال‌های HTTPS، SQL، وظیفه اجرای خودکار و WSL تغییر نمی‌کنند.
فایل navigationOrder.test.ts برای بررسی توسعه‌دهنده همراه بسته است؛ نصاب آن را کپی نمی‌کند.
مسیر فعلی پروژه: C:\Users\Mitra\Desktop\Tekarai
پشتیبان منو: C:\ProgramData\Tekarai\MenuBackups
پشتیبان مسیر release قبلی: C:\ProgramData\Tekarai\Deployment
این بسته دیتابیس یا نسخه پشتیبان اطلاعات کاربران نیست.

اعتبارسنجی محلی: ۲۵ تست مرتبط و npm run build کامل موفق؛ متادیتای هر ۴۵ آیتم (لینک، مجوز، برچسب و پرچم) با نسخه قبلی یکسان است و فقط ترتیب تغییر کرده است. اجرای نصاب PowerShell روی ویندوز کاربر هنوز تأیید نشده است.
