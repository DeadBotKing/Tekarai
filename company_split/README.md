# تفکیک شرکت به ازای هر دارو + کلیک برای جزئیات

هر دو مدل پشتیبانی شد:
- بعضی خط‌ها اختصاصی یک شرکت (مثلا خط ۱ فقط روناک)
- بعضی خط‌ها اشتراکی: داخل یک خط، داروی A برای روناک، داروی B برای آرنگ (نمونه: خط سرنگ 5ml و آمپول 2ml الان دو ردیف دارند: روناک + آرنگ/حکیمان)

چی شد:
1. هر ردیف دارو حالا ستون "شرکت (دارو)" دارد — در ویرایش dropdown روناک/آرنگ/رونافارمد/حکیمان/زیست‌دارو
2. کارت‌های "تفکیک شرکت‌ها" و دونات‌ها بر اساس شرکت دارو حساب می‌شوند نه شرکت خط
3. فیلتر شرکت روی دارو اعمال می‌شود (نه خط) — بزن آرنگ فقط ردیف‌های آرنگ می‌ماند
4. روی نام هر دارو (یا روی برش دونات "تولید به تفکیک دارو") کلیک کن → پاپ‌آپ باز می‌شود که نشان می‌دهد همین دارو (مثلا سرنگ 5ml) چقدرش روناکه چقدرش آرنگ/حکیمان، با درصد
