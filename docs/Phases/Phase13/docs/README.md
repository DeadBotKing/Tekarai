## Starting assumption

The previous Tekarai implementation is lost and must be rebuilt from zero.

## Important scope note

These documents define the architectural and execution baseline.
Detailed entity-by-entity ERD, field dictionary, complete API catalog,
permission matrix, and detailed ADR set must be designed and approved
during their corresponding phases. They must not be invented merely to
make the handoff appear complete.

The correct behavior for an unspecified requirement is to stop, document
the Open Question, resolve it, and continue.
