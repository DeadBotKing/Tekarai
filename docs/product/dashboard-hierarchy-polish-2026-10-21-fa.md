# تحویل گذر سلسله‌مراتب داشبورد Tekarai

**تاریخ:** ۲۱ اکتبر ۲۰۲۶
**نسخهٔ برنامه:** `0.19.0` (بدون تغییر)
**دامنه:** اولویت‌بندی و اندازهٔ عناصر داشبورد؛ بدون بازطراحی پالت یا منطق کسب‌وکار.

## تغییرات

- KPIها و اقدام‌های سریع در ابتدای صفحه و پیش از ویجت‌های عملیاتی قرار گرفتند؛ راهنمای شروع و نقشهٔ بخش‌ها بعد از ویجت‌ها باقی ماندند.
- چهار KPI در دسکتاپ خواناتر شده‌اند و در موبایل دو ستونه می‌مانند. اندازه و وزن متن فارسی و عنوان ویجت‌ها نیز در محدودهٔ داشبورد تقویت شد.
- ایجاد وظیفه اقدام اصلی آبی است؛ اگر مجوز آن وجود نداشته باشد، ایجاد پروژه به‌عنوان اقدام اصلی نمایش داده می‌شود. باقی اقدام‌ها همچنان تابع `PermissionGuard` هستند.
- نقشهٔ فضای کاری در حالت جمع‌شده نمایش داده می‌شود. دکمهٔ قابل‌دسترس آن `aria-expanded` و `aria-controls` دارد؛ CTAهای راهنمای شروع آن را باز می‌کنند و فهرست پیوندها همچنان بر اساس مجوز پالایش می‌شود.
- dismiss/restore راهنمای شروع حفظ شد. هیچ API، دادهٔ ساختگی، مجوز یا قابلیت تجاری تازه‌ای اضافه نشد.
- CSS جدید فقط به `.page--dashboard` محدود است. سطوح گرم و پالت موجود حفظ شده‌اند؛ accent چهار KPI در روشن `#537b5f` و در تیره `#89b493` باقی مانده است.

## بررسی و اعتبارسنجی

- `npm run build` — موفق؛ هشدار شناخته‌شدهٔ Vite برای chunkهای بالای ۵۰۰ kB باقی است.
- `npm test -- --run src/tests/dashboardOnboarding.test.tsx` — **۳ از ۳ موفق**؛ بازشدن/بسته‌شدن نقشه، CTA راهنما و فیلتر مجوز پوشش داده شده‌اند.
- `npm run verify:demo-boundary` — موفق؛ ۷۰ artifact بررسی شد و رکورد ساختگی در build پیدا نشد (استثنای ازپیش‌موجود: الگوی import با «بلبرینگ 6204»).
- `git diff --check` — موفق.
- مرور واقعی RTL با Playwright: دسکتاپ ۱۴۴۰ پیکسل و موبایل ۳۹۰ پیکسل در روشن و تیره؛ موبایل ۳۲۰ پیکسل نیز در تیره، از جمله نقشهٔ بازشده.
- در عرض ۳۲۰ پیکسل، `documentElement.scrollWidth` و `body.scrollWidth` هر دو برابر ۳۲۰ بودند؛ کنسول مرورگر **۰ خطا و ۰ هشدار** داشت.

## افزونهٔ استیکرهای زمینه‌ای

- `ContextSticker` با چند آیکون SVG، سه tone و اندازه‌های محدود اضافه شد؛ استیکرها تزئینی‌اند (`aria-hidden`) و هیچ متن، وضعیت، قانون یا داده‌ای را جایگزین نمی‌کنند.
- کاربردها محدود ماندند: empty state وظایف/درخواست‌های کار/داشبورد نگهداری و داشبورد بدون ویجت؛ نشان نوع درخواست کار در فهرست و برد؛ راهنمای شروع داشبورد؛ و toast موفقیت ایجاد وظیفه یا درخواست کار.
- برای خطاها استیکر موفقیت نمایش داده نمی‌شود. API، مجوز یا رکورد ساختگی تازه‌ای به‌عنوان قابلیت محصول اضافه نشد.

### بررسی افزونه

- `npm run build` — موفق؛ هشدار شناخته‌شدهٔ Vite دربارهٔ chunkهای بالای ۵۰۰ kB باقی است.
- `npm test -- --run src/tests/components.test.tsx src/tests/dashboardOnboarding.test.tsx` — **۷ از ۷ موفق**.
- `npm run verify:demo-boundary` — موفق؛ ۱۲۶ artifact بررسی شد، بدون رکورد ساختگی (به‌جز استثنای ازپیش‌موجودِ الگوی import با «بلبرینگ 6204»).
- `git diff --check` و بررسی whitespace فایل‌های تغییرکرده — موفق.
- مرور بصری RTL در ۱۴۴۰ پیکسل (داشبورد، فهرست و برد درخواست‌های کار؛ روشن/تیره) و ۳۹۰ پیکسل (حالت خالی و نشان‌ها) انجام شد. در ۳۲۰ پیکسل، عرض `documentElement` و `main` برابر viewport (۳۲۰px) بود؛ اسکرول افقی تازه‌ای دیده نشد.
- toast موفقیت ایجاد وظیفه و درخواست کار در حالت نمایشی دیده شد؛ ایجادهای آزمایشی در حالت نمایشیِ بدون ذخیره در پایگاه‌داده بودند.
- هنگام بازکردن صفحهٔ درخواست‌های کار، دو درخواست پس‌زمینه به `/api/v1/maintenance/team/reservations` به‌علت در دسترس نبودن backend محلی روی پورت ۸۰۰۰ با `ECONNREFUSED`/HTTP 500 شکست خوردند؛ خود صفحه و برچسب‌ها رندر شدند. این مورد به استیکرها مربوط نیست.
