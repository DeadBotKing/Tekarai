# تحویل زیباسازی UI نگهداری — v0.19.0

## دامنه

این پاس بر پایهٔ teardown موجود در `teardown-maintainx-limble-v0.18.0-fa.md` انجام شده است. هدف، پرداختن به UI فعلی Tekarai بود؛ نه ساخت برد موازی یا تغییر قواعد گردش کار. نسخهٔ پروژه عمداً روی `0.19.0` باقی مانده است.

## تغییرات

- **Kanban دستورکار:** همان برد موجود حفظ شد و ستون‌ها با وضعیت‌های واقعی گردش کار هماهنگ شدند؛ از جمله «در انتظار تأیید» و «لغوشده». برد در RTL به‌صورت افقی پیمایش می‌شود و کارت‌ها اولویت، دستگاه، مسئول، تاریخ ثبت/مهلت SLA و هشدار تأخیر را نشان می‌دهند.
- **جزئیات دستورکار:** پنجرهٔ عریض‌تر با سربرگ و پابرگ ثابت، محتوای قابل پیمایش، خلاصهٔ تجهیز و میان‌برهای بخش‌ها اضافه شد. رویدادهای واقعی سیستم در قالب تایم‌لاین مرتب‌تر نمایش داده می‌شوند.
- **کارت‌های داشبورد نگهداری:** هم‌ترازی، سلسله‌مراتب اعداد و بازهٔ انتخاب تاریخ پرداخت شده و رنگ‌ها از design tokenهای موجود می‌آیند.
- **پروندهٔ تجهیز:** تب «اسناد و دفترچه‌ها» به پروفایل تجهیز اضافه شد و از همان سرویس پیوست و کنترل دسترسی موجود استفاده می‌کند.
- **ترجمه و دسترس‌پذیری:** برچسب‌های بخش‌های جدید به فارسی و انگلیسی افزوده شده‌اند؛ پیمایش برد و جزئیات در عرض‌های باریک هم در نظر گرفته شده است.

## محدودیتِ آگاهانه

در workspace برای دستورکار، event history واقعی وجود دارد؛ اما API یا comment stream پایدارِ متصل به دستورکار در کد بررسی‌شده موجود نبود. بنابراین این تغییر تاریخچهٔ واقعی را زیباتر می‌کند و پیام ساختگی یا فرم گفت‌وگوی بی‌پشتوانه اضافه نمی‌کند. برای گفت‌وگوی ثبت‌پذیر باید API/مدل مرتبط با work order طراحی و پیاده‌سازی شود.

## رفتارهای کسب‌وکار

گردش وضعیت‌ها، منطق تعمیر اساسی در برابر مصرفی، تأیید انسانی شدت تعمیر و advisory بودن پیشنهاد AI در این پاس تغییر نکرده‌اند.

## اعتبارسنجی

- `frontend-web`: `npm run build` — موفق؛ Vite فقط هشدار موجود دربارهٔ chunkهای بزرگ‌تر از 500 kB را گزارش کرد.
- تست‌های هدفمند UI/نگهداری و ترجمه: 32 تست در 4 فایل — موفق. (شامل برد و میان‌بر تایم‌لاین دستورکار، پروفایل تجهیز، داشبورد نگهداری و ترجمه.)
- `npm run verify:demo-boundary` — موفق؛ 70 artifact بررسی‌شده و بدون رکورد ساختگی.
- تست سراسری frontend و تست مرورگری در این پاس اجرا نشده‌اند.
